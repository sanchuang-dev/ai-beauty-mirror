# 美容院智能美妆镜 · 安卓平板原型说明

版本：v1（2026-10-15）　载体：安卓平板（原型以浏览器中的平板画框模拟）　面向人群：美容院到店女性顾客

---

## 一、产品定位

一台立在美容房里的安卓平板美妆镜，顾客无需店员陪同即可完成"看肌肤 → 调光线 → 选妆容"三件事。原型把这三步做成了可以真实点击走完的流程，用于向门店、投资方或研发团队演示产品形态与交互逻辑。

设计取向：

- **面向女性顾客的体验语言**：深色镜面质感 + 香槟金 + 柔粉，文案避免"诊断""问题肌"等压迫性表达，改用"肌肤档案""今日状态"。
- **面向美容院的场景适配**：所有结果页都留了"预约美容顾问"的转化入口，测肤结果同时是门店的服务依据与销售线索。
- **平板优先**：触控目标不小于 44px，主操作按钮通栏放置，方便顾客站立或坐姿单手操作。

## 二、页面结构

| 页面 | 作用 | 进入方式 |
|---|---|---|
| 待机镜面页 | 品牌待机态，暗示"这是一面镜子" | 默认首屏 |

## 三、功能说明与验收对照

### REQ-001 智能测肤

点击「开始测肤」后，取景框出现虚线定位框与上下扫描光带，进度文案依次经历"面部定位 → 水润度 → 油脂分布 → 毛孔与屏障 → 生成档案"五步，约 4 秒后输出结果卡：

- **总分**（0–100）与**肤质类型**（中性 / 偏干 / 偏油 / 混合性）
- **四维指标**：水润度、清爽度、细腻度、强韧度
- **护理建议**：按各项短板自动生成 1–4 条，每条标注重点词
- 页面底部出现「重新测肤」，可随时重跑

结果同时回填到镜面主界面的「今日肌肤档案」侧卡，并驱动妆容推荐的排序。

### REQ-002 灯光调节

- 左侧是镜面前实时预览区，右侧为**色温滑杆**（2700K–6500K）与**亮度滑杆**（20%–100%）。
- 拖动时预览区的补光颜色与明暗实时变化，滑杆数值同步显示（如 `5000K`、`70%`）。
- 四组预设光效：**自然光 / 暖光氛围 / 精致妆光 / 日光还原**，点击一键切换并在预览区下方标注当前光效名。
- 手动拖动滑杆会切到"自定义"状态；灯光设置会同步作用于镜面主界面的补光层，切换页面后依然保持。

### REQ-003 妆容推荐

内置四套妆容，各自对应一类肌肤状态：

| 妆容 | 适配 | 妆效 |
|---|---|---|
| 水光裸感妆 | 偏干、要通透 | 保湿底妆、伪素颜 |
| 雾面轻羽妆 | 混油、要持妆 | 柔焦半雾面 |
| 桃粉舒缓妆 | 敏感泛红 | 精简低刺激 |
| 瓷肌细化妆 | 毛孔粗大 | 奶油肌平整妆面 |

- 每套卡片展示色板、名称、妆效定位、适用标签与一句话说明。
- 点击卡片进入详情：5 步上妆流程（分步序号）+ 建议用品清单（品名与用途）+「预约美容顾问 1 对 1 上妆指导」按钮，点击后给出预约反馈提示。
- 未测肤时顶部提示"先完成智能测肤，可获得为您定制的妆容优先级"；已测肤时按分数短板自动锁定推荐款，卡片打上"为你推荐"标记。

### REQ-004 横竖屏双布局

原型画框下方提供「横屏 16:10 / 竖屏 10:16」切换按钮，用于现场演示两种安装形态：

- **横屏**：镜面区在左（约 68%），右侧纵向排列肌肤档案与三个功能入口，适合台式摆放或墙面平视安装。
- **竖屏**：镜面区在上，肌肤档案与功能入口转为底部横向轨道，更接近立式落地镜的形态；灯光页与妆容页同步改为纵向堆叠并可滚动。

### REQ-005 镜面开关与待机

待机页含镜面轮廓、品牌名"镜 · 悦颜"与呼吸式提示文案，轻触任意位置进入镜面主界面并弹出提示。各功能页均有「返回镜面」，形成完整的页面闭环。

## 四、数据与运行边界

- 测肤数值在合理区间内随机生成，**属示例数据，不代表真实皮肤检测结果**，也不构成医疗或皮肤学诊断。
- 肌肤档案与灯光设置保存在当前浏览器本地，同一浏览器再次打开时保留；点击「重置演示数据」可回到初始待机状态。
- 本原型为纯前端可交互演示，未连接真实的皮肤检测算法、会员系统、商品库或预约服务。真要落地，需另行评估摄像头取帧与检测算法方案、门店会员体系对接、以及产品库与库存数据源。

## 五、如何打开体验

1. 打开文件夹 `美妆镜原型`，双击 `美妆镜原型.html`（浏览器会自动全屏显示平板画框）。
2. 建议按这条路径演示完整故事：**轻触待机页 → 智能测肤 → 查看档案 → 灯光调节 → 妆容推荐 → 打开详情 → 点预约**。
3. 演示到中途可切换横竖屏，展示两种安装形态下的界面重排。

## 六、可继续迭代的方向

- 增加**门店运营视角**：会员登录、历史测肤曲线、消费与预约记录。
- 增加**产品导购闭环**：妆容详情直接关联门店在售商品与试用申请。
- 接入**真实检测能力**：摄像头取帧 + 皮肤检测算法，替换现有随机数值。
- 补充**多语言与无障碍**：字号放大、色彩对比度、语音引导，覆盖年龄层更高的客群。
